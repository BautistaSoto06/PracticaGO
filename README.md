# PracticaGO

Proyecto realizado en Go con el objetivo de practicar conceptos básicos de programación, organización de código y testing.

## Funcionalidades

- Gestión de libros
- Gestión de usuarios
- Solicitud de préstamos de libros
- Validación de libros existentes
- Tests automáticos
- Integración Continua con GitHub Actions

## Tecnologías utilizadas

- Go
- Testify
- GitHub Actions

## Cómo ejecutar los tests

```bash
go test ./...
```

## Cómo ejecutar los tests con cobertura
```bash
go test ./... -cover
```
